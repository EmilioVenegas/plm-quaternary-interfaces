# --- Optional fused-kernel stack (not installed by bin/setup.sh) -------------
# ESMC probes for these at import and falls back to eager attention / plain
# PyTorch LayerNorm+MLP when they are absent. The fallback is numerically
# non-identical, but the drift lives on the *unnormalized* residual stream:
# after the final LayerNorm the two paths agree to within a few ULP, so any
# measurement taken in logit space (masked log-probs, log-odds ratios, the
# additive/joint/conditional pair scores) is rounding-noise safe without them.
# Install before a publication run so the reported numbers come off the same
# kernels the model was released with; skip for iteration, they are slow to
# build and pull a compiler toolchain.
